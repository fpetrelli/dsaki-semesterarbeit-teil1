# DSAKI Semesterarbeit Teil 1 – Betriebsblatt Raum 4.130

Interaktives Betriebsblatt eines Seminarraums der HafenCity Universität Hamburg (Forschungsprojekt DROPS),
erstellt im Semesterprojekt DASKI, B.Sc. Technische Gebäudeausrüstung.

**Seite:** https://fpetrelli.github.io/dsaki-semesterarbeit-teil1/

- `index.html` ist eine einzelne, in sich geschlossene Seite; die aufbereiteten Betriebsdaten sind
  komprimiert eingebettet, es gibt kein Backend und keine externen Abhängigkeiten.
- `build.json` nennt die Hashes der veröffentlichten Seite und den Quell-Commit der Analyse-Pipeline.
- Dieses Repository wird automatisch von `bopa publish` befüllt – nicht von Hand bearbeiten.
